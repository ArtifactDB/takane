

# bigBed file (1.0)

## Overview

The `bigbed_file` specification describes the on-disk representation of a bigBed file.
This allows more complex objects to portably store a reference to a bigBed file, e.g., a [`simple_list`](../simple_list) object of multiple files.

## Object metadata

The `OBJECT` file should contain a `bigbed_file` property, itself a JSON object with the following properties:

- `version`, a string specifying the version of the `bigbed_file` format.
  This should be set to "1.0".

## Directory structure

### Contents

The directory should contain:

- `OBJECT`, a JSON file as described above.
- `file.bb`, the bigBed file.

### `file.bb`

The `file.bb` file should follow the [bigBed format](https://doi.org/10.1093/bioinformatics/btq351).
