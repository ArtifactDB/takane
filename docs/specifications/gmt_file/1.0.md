

# GMT file (1.0)

## Overview

The `gmt_file` specification describes the on-disk representation of a GMT file.
This allows more complex objects to portably store a reference to a GMT file, e.g., a [`simple_list`](../simple_list) object of multiple files.

## Object metadata

The `OBJECT` file should contain a `gmt_file` property, itself a JSON object with the following properties:

- `version`, a string specifying the version of the `gmt_file` format.
  This should be set to "1.0".

## Directory structure

### Contents

The directory should contain:

- `OBJECT`, a JSON file as described above
- `file.gmt.gz`, a Gzip-compressed GMT file

### `file.gmt.gz`

The `file.gmt.gz` file should follow [the Gene-Matrix-Transposed format](https://docs.gsea-msigdb.org/#GSEA/Data_Formats/#gmt-gene-matrix-transposed-file-format-gmt).
