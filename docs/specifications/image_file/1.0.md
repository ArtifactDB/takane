

# Image file (1.0)

## Overview

The `image_file` specification describes an on-disk representation for an image file in one of the standard formats.
This allows more complex objects to portably store references to images, e.g., [`spatial_experiment`](../spatial_experiment). 

## Object metadata

The `OBJECT` file should contain a `bam_file` property, itself a JSON object with the following properties:

- `version`, a string specifying the version of the `bam_file` format.
  This should be set to "1.0".
- `format`, a string specifying the format of the file.
  This may be one of `"PNG"`, `"TIFF"`, `"JPEG"`, `"GIF"` or `"WEBP"`.

## Directory structure

### Contents

The directory should contain:

- `OBJECT`, a JSON file as described above.
- `file.png`, a PNG file if `format = "PNG"`.
- `file.tif`, a TIFF file if `format = "TIFF"`.
- `file.jpg`, a JPEG file if `format = "JPEG"`.
- `file.gif`, a GIF file if `format = "GIF"`.
- `file.webp`, a WEBP file if `format = "WEBP"`.

### `file.png`

The `file.png` file should follow the [PNG specification](https://www.libpng.org/pub/png/spec/1.2/PNG-Structure.html).

### `file.tif`

The `file.tif` file should follow the [TIFF specification](https://www.itu.int/itudoc/itu-t/com16/tiff-fx/docs/tiff6.pdf).

### `file.jpg`

The `file.jpg` file should follow the [JPEG 1 specification](https://jpeg.org/jpeg/).

### `file.gif`

The `file.gif` file should follow the GIF specification (version [87a](https://www.w3.org/Graphics/GIF/spec-gif87.txt) or [89a](https://www.w3.org/Graphics/GIF/spec-gif89a.txt)).

### `file.webp`

The `file.webp` file should follow the [WEBP specification](https://developers.google.com/speed/webp/docs/riff_container).
