

# Ranged summarized experiment (1.0)

## Overview

The `ranged_summarized_experiment` specification describes an on-disk representation of a ranged summarized experiment. 
This is a summarized experiment that also stores the genomic location corresponding to each row.
It is based on the `RangedSummarizedExperiment` class from the [**SummarizedExperiment** Bioconductor package](https://bioconductor.org/packages/SummarizedExperiment).

The `ranged_summarized_experiment` specification is derived from the [`summarized_experiment` specification](../summarized_experiment).
A ranged summarized experiment can be used anywhere that a summarized experiment is expected.

## Object metadata

The `OBJECT` file should contain a `ranged_summarized_experiment` property, which is itself a JSON object with the following properties:

- `version`, a string specifying the version of the `ranged_summarized_experiment` format.
  This should be set to "1.0".

In addition, the `OBJECT` file should contain all properties expected by the [`summarized_experiment`](../summarized_experiment) specification. 

## Directory structure

### Contents

The directory should contain:

- `OBJECT`, a JSON file as described above.
- All files expected of the [`summarized_experiment`](../summarized_experiment) format.

Optionally, it may contain:

- `row_ranges/`, a subdirectory.
- Any of the files that may be present in the [`summarized_experiment`](../summarized_experiment) format.

### `row_ranges/`

The `row_ranges/` should contain a child object that is a [genomic ranges](../genomic_ranges) or a [genomic ranges list](../genomic_ranges_list).
The height of the child object should be equal to the number of rows in the ranged summarized experiment (see ["Dimensions"](#dimensions) below).
The $i$-th entry of the child object contains the genomic coordinates of the $i$-th row of the ranged summarized experiment.

Note that any names in the `row_ranges/` child object should not be used as the row names of the ranged summarized experiment.
The row names are instead taken from the `row_data/` of the `summarized_experiment` specification.
This represents a minor deviation from the default implementation of the Bioconductor package.

If `row_ranges/` is not present, it is assumed that the ranged summarized experiment has no genomic coordinates.
This is typically represented by a [genomic ranges list](../genomic_ranges_list) of length equal to the number of rows,
where each list element is an empty genomic ranges object.

## Height

The height of a ranged summarized experiment is defined in the same manner as its base [summarized experiment](../summarized_experiment).

## Dimensions

The dimensions of a ranged summarized experiment are defined in the same manner as its base [summarized experiment](../summarized_experiment).

## Interfaces

A ranged summarized experiment satisfies the `SUMMARIZED_EXPERIMENT` interface.
