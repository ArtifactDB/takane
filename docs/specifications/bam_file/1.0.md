

# BAM file (1.0)

## Overview

The `bam_file` specification describes the on-disk representation of a BAM file.
This allows more complex objects to portably store a reference to a BAM file, e.g., a [`simple_list`](../simple_list) object of multiple files.

## Object metadata

The `OBJECT` file should contain a `bam_file` property, itself a JSON object with the following properties:

- `version`, a string specifying the version of the `bam_file` format.
  This should be set to "1.0".

## Directory structure

### Contents

The directory should contain:

- `OBJECT`, a JSON file as described above.
- `file.bam`, a BAM file.

Optionally, it may also contain one or both of:

- `file.bam.bai`, a BAM index file.
- `file.bam.csi`, a CSI index file.

### `file.bam`

The `file.bam` file should be formatted as described in the [BAM specification](https://samtools.github.io/hts-specs/SAMv1.pdf).

### `file.bam.bai`

The `file.bam.bai` should be an index into `file.bam`, 
following the format described in the [BAM specification](https://samtools.github.io/hts-specs/SAMv1.pdf).

### `file.bam.csi`

The `file.bam.csi` file should be an index into `file.bam`, following the [CSI specification](https://samtools.github.io/hts-specs/CSIv1.pdf).
