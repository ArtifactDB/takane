

# FASTA file (1.0)

## Overview

The `fasta_file` specification describes the on-disk representation for a FASTA file.
This allows more complex objects to portably store a reference to a FASTA file, e.g., a [`simple_list`](../simple_list) object of multiple files.

## Object metadata

The `OBJECT` file should contain a `fasta_file` property, itself a JSON object with the following properties:

- `version`, a string specifying the version of the `fasta_file` format.
  This should be set to "1.0".
- `indexed`, a boolean indicating whether the FASTA file has been indexed.
- `sequence_type`, a string specifying the sequence type.
  This should be one of `"DNA"`, `"RNA"`, `"AA"` or `"custom"`.

## Directory structure

### Contents

The directory should contain:

- `OBJECT`, a JSON file as described above.

If `indexed = false`, the directory should also contain:

- `file.fasta.gz`, a Gzip-compressed FASTA file.

If `indexed = true`, the directory should instead contain:

- `file.fasta.bgz`, a BGZF-compressed FASTA file.
- `file.fasta.fai`, the FASTA index file.
- `file.fasta.bgz.gzi`, the BGZF index file.

### `file.fasta.gz`

The `file.fasta.gz` file should follow the [FASTA format](https://www.ncbi.nlm.nih.gov/genbank/fastaformat/).
Sequences in this file should use the alphabet specified by the `sequence_type` property in the object metadata.

### `file.fasta.bgz`

The `file.fasta.bgz` file should follow the [FASTA format](https://www.ncbi.nlm.nih.gov/genbank/fastaformat/).
Sequences in this file should use the alphabet specified by the `sequence_type` property in the object metadata.

This file should be compressed using the [blocked GNU Zip format](https://www.htslib.org/doc/bgzip.html).

### `file.fasta.fai`

The `file.fasta.fai` file should contain offsets into the uncompressed contents of `file.fasta.bgz`.

### `file.fasta.bgz.gzi`

The `file.fasta.bgz.gzi` file should contain the byte offset mappings of the uncompressed contents of `file.fasta.bgz` to the compressed file.
