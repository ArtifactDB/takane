

# FASTQ file (1.0)

## Overview

The `fastq_file` format specifies the expected representation for a FASTQ file.

## Object metadata

The `OBJECT` file should contain a `fastq_file` property, itself a JSON object with the following properties:

- `version`, a string specifying the version of the `fastq_file` format.
  This should be set to "1.0".
- `indexed`, a boolean indicating whether the FASTQ file has been indexed.
- `sequence_type`, a string specifying the sequence type.
  This should be one of `"DNA"`, `"RNA"`, `"AA"` or `"custom"`.
- `quality_type`, a string specifying the quality encoding type.
  This should be one of `"phred"` or `"solexa"`.
- `quality_offset`, a string specifying the offset for quality encodings when `quality_type = "phred"`.
  This should be one of 33 or 64.

## Directory structure

### Contents

The directory should contain:

- `OBJECT`, a JSON file as described above.

If `indexed = false`, the directory should also contain:

- `OBJECT`, a JSON file as described above.
- `file.fastq.gz`, a Gzip-compressed FASTQ file.

If `indexed = true`, the directory should instead contain:

- `file.fastq.bgz`, a BGZF-compressed FASTQ file.
- `file.fastq.fai`, the FASTQ index file.
- `file.fastq.bgz.gzi`, the BGZF index file.

### `file.fastq.gz`

The `file.fastq.gz` file should follow the [FASTQ format](https://pmc.ncbi.nlm.nih.gov/articles/PMC2847217/).
Sequences in this file should use the alphabet specified by the `sequence_type` property in the object metadata.
Similarly, quality strings in the file should follow the quality encoding defined by `quality_type` and `quality_offset`.

### `file.fastq.bgz`

The `file.fastq.bgz` file should follow the [FASTQ format](https://pmc.ncbi.nlm.nih.gov/articles/PMC2847217/).
Sequences in this file should use the alphabet specified by the `sequence_type` property in the object metadata.
Similarly, quality strings in the file should follow the quality encoding defined by `quality_type` and `quality_offset`.

This file should be compressed using the [blocked GNU Zip format](https://www.htslib.org/doc/bgzip.html).

### `file.fastq.fai`

The `file.fastq.fai` file should contain offsets into the uncompressed contents of `file.fastq.bgz`.

### `file.fastq.bgz.gzi`

The `file.fastq.bgz.gzi` file should contain the byte offset mappings of the uncompressed contents of `file.fastq.bgz` to the compressed file.
