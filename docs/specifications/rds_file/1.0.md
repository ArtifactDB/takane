

# RDS file (1.0)

## Overview

The `rds_file` format specifies the expected representation for a RDS file.
This allows more complex objects to portably store a reference to a RDS file, e.g., a [`simple_list`](../simple_list) object of multiple files.

RDS is the serialization format for the R programming language and is best avoided for applications that need interoperability between languages.
The format itself requires some guesswork to parse, and there are no checks on the content of the file (e.g., users can save any arbitrary object).
Nonetheless, we list it here as it may be occasionally necessary to save objects that have no better representation in **takane**.

## Object metadata

The `OBJECT` file should contain a `rds_file` property, itself a JSON object with the following properties:

- `version`, a string specifying the version of the `rds_file` format.
  This should be set to "1.0".

## Directory structure

### Contents

The directory should contain:

- `OBJECT`, a JSON file as described above.
- `file.rds`, an RDS file.

### `file.rds`

The `file.rds` file should be an RDS file created in binary format with Gzip-compression.
File contents should be formatted as described in the [R internals documentation](https://cran.r-project.org/doc/manuals/r-release/R-ints.html#Serialization-Formats).
