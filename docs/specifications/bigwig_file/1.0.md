

# bigWig file (1.0)

## Overview

The `bigwig_file` specification describes the on-disk representation of a bigWig file.
This allows more complex objects to portably store a reference to a bigWig file, e.g., a [`simple_list`](../simple_list) object of multiple files.

## Object metadata

The `OBJECT` file should contain a `bigwig_file` property, itself a JSON object with the following properties:

- `version`, a string specifying the version of the `bigwig_file` format.
  This should be set to "1.0".

## Directory structure

### Contents

The directory should contain:

- `OBJECT`, a JSON file as described above.
- `file.bw`, a bigWig file.

### `file.bw`

The `file.bw` file should follow the [bigWig format](https://pmc.ncbi.nlm.nih.gov/articles/PMC2922891/).
