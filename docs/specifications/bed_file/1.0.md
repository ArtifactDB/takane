

# BED file (1.0)

## Overview

The `bed_file` specification describes the on-disk representation of a BED file.
This allows more complex objects to portably store a reference to a BED file, e.g., a [`simple_list`](../simple_list) object of multiple files.

## Object metadata

The `OBJECT` file should contain a `bed_file` property, itself a JSON object with the following properties:

- `version`, a string specifying the version of the `bed_file` format.
  This should be set to "1.0".
- `indexed`, a boolean indicating whether the BED file has been indexed.

## Directory structure

### Contents

The directory should contain:

- `OBJECT`, a JSON file as described above.

If `indexed = false`, the directory should also contain:

- `file.bed.gz`, a Gzip-compressed BED file.

If `indexed = true`, the directory shouhld instead contain:

- `file.bed.bgz`, a BGZF-compressed BED file. 
- `file.bed.bgz.tbi`, a Tabix file.

### `file.bed.gz`

The `file.bed.gz` file should be formatted as described in the [BED specification](https://samtools.github.io/hts-specs/BEDv1.pdf).

### `file.bed.bgz`

The `file.bed.bgz` file should be formatted as described in the [BED specification](https://samtools.github.io/hts-specs/BEDv1.pdf).

This file should be compressed using the [blocked GNU Zip format](https://www.htslib.org/doc/bgzip.html).

### `file.bed.bgz.tbi`

The `file.bed.bgz.tbi` should be an index into `file.bed.bgz` following the [Tabix format](https://samtools.github.io/hts-specs/tabix.pdf).
